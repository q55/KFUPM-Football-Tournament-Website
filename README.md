# KFUPM Football Tournament System

This project is a full-stack web application for managing football tournaments at KFUPM.

## Technologies
- React (Frontend)
- Node.js + Express (Backend)
- MySQL (Database)
- TailwindCSS

## Features
- Guest: Browse match results, top scorers, team info
- Admin: Add tournaments, manage teams, assign captains
- System: Match reminder emails, score triggers, login/logout

## Setup

```bash
cd frontend
npm install
npm start
